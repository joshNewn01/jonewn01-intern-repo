# Understand the Competitive Landscape

## Task

### Researching other productivity apps

#### Freedom
    - Similar to Focus Bear in function, different in overall goal (aiming for generalized blocking and focus help - not specialized for AuDHD individuals)
        - Can block apps, games, and websites
        - Cross-device syncing
        - Can block the whole Internet
        - Can schedule focus sessions to be automatically recurring at set times/days
        - Utilizes calming soundscapes (Focus Sounds)
        - Has a 'locked mode' (just Grizzly Bear mode)

#### Cold Turkey
    - Mainly appears to be a general website blocker
        - Can block/allow specific websites
        - Can block applictions and games
        - Can block whole keyword searches
        - Can block the whole Internet/your host PC
        - Can set weekly schedules, passwords, and allowances and breaks
        - Can set which users are affected by said blocks
        - Can track website and app usage
        - Uninstall prevention
    - Though the app seems similar in concept, this one appears to be heavily focused on restricting access to disctracting sites/apps and helping manage healthier media consumption/screentime habits as opposed to aiding in general habit building/life organization

#### Tiimo
    - A visual AI planner (seems to aim for general life scheduling/planning)
    - Same goal as Focus Bear - adaptive planning/focusing tools to aid neurodivergent users
        - Flexible planning
            - Tiimo readjusts schedules to aid users in adapting to any unexpected situation
        - Customizable visuals
            - Can customize the appearance of the app
            - Can structure your schedule via a visual timeline
        - Widgets, Live activities and Dynamic Island
            - Can view app data/stats and even interact with the app via widgets
        - To-do list
            - Incredibly similar in concept and function to Focus Bear's

#### Routinery
    - Seemingly the closest to Focus Bear in functionality
    - Routine timer
        - Uses a timer for each routine you set
    - Mood tracking
        - Allows you to record your daily mood and track it
    - AI app integration
        - Allow AI apps like ChatGPT, Claude, and/or Gemini manage your routines
    - Widgets
        - Add widgets to your lock/home screens
    - Dark Mode
        - Has a dark mode
    - Customizable bottom menu (tab menu)
        - Can customize the layout of the tabs within the navigation menu
    - Customizable app icon
        - Can change the app's icon in your home screen
    - Start links
        - Each routine has a unique start link, can be accessed via your calendar, notes, etc.
    - (iOS Only) Siri Shortcuts
        - Can start routines via verbal commands to Siri
    - (iOS Only) Shortcutes Automation
        - Can be connected to the Shortcuts app in iOS to autostart routines at specific times or locations
    - Timer Features
        - Routine Start Screen
            - Can set a start screen to help in entering a calmed, focused state or view the day's upcoming tasks
        - Voice Assistant
            - Can have a voice assistant verbally tell you when/what the next task is
        - Auto-next
            - Timer automatically moves to the next step to ensure that the routine is completed without any extra effort
        - White Noise
            - Can set your own white noise to play during a routine
        - Context
            - Attach inspiring quotes or Youtube links to the task
        - Reorder tasks
            - Can reorder your tasks in line with life events
        - Add tasks in real time
            - Add tasks to your routine as it is going
        - Focus Mode
            - Blocks distracting apps
        - Hide remaining time
            - Can hide remaining time if numbers/timers are too stressful

## Reflection

### What makes Focus Bear different from these apps?

    Though some of these apps boast the same features and goals, Focus Bear is different in how it approaches its philosophy of ensuring Focus is retained. From my observations, most of these apps fall under the category of focus application that Focus Bear aimed to be different from - they are designed to be too soft. Though all of them feature some sort of "lock out" mode or allow for adaptable strictness levels, Focus Bear seems to be the only one that considers the true breadth of people's needs in strictness, allowing for a varying strictness scale for their blocking/focus sessions as opposed to just "normal" and "lockdown, super-strict". Outside of the general functionality, Tiimo appears to be the only competitor that is in the exact same space goal-wise - helping neurodivergent (primarily AuDHD/dyslexic) individuals create healthy habits and routines, while the other three appear to be generalized blockers or productivity apps.

### If you were a user, why would you choose Focus Bear over competitors?

    If I was a potential user, I would chose Focus Bear over the competitors because it seems to be the only app that is truly flexible with the user's schedule, allowing it to be as strict or lenient as best fitting to my (the user's) focusing needs, while also providing a healthy an encouraging way of managing and practicing good routines and habits.

### What's one feature that other apps have that Focus Bear doesn't?

    From my research one feature that Focus Bear does not use that other apps do is native integration with AI assistants like Siri.

### Based on your research, what's one improvement you think Focus Bear could make?

    For me, the one improvment I would love to see implemented from the other applications is the previously mentioned scheduling Focus Sessions so they automatically begin at set days and times for a set period of time, as this would allow for users to jump straight into their work when they need to with all the settings, blocks, and stat tracking already in place.
