### Note 3-5 things about the how the app is meant to work that are relevant to your role

 - Focus Bear utilizes AI to pay attention to websites or apps that will distract you.
    - Sends an alert warning of a drop in 'Focus Alignment Score'
    - Will full block the site (if set to strict mode)
 - Strictness Types
    - Normal - allows you to end the session at any time, warns you before blocking a website
    - Strict - requires you to wait 15 seconds before you can stop the session
    - Super Strict - you MUST wait until the session completes and all distracting sites are immediately blocked
 - Focus Mode
    - You can create your own Focus Mode with custom-set parameters
    - Can set 'keywords' that will be found in website pages/visited apps that the AI can block/allow based on the permissions you set
 - Allow vs. Block
    - Allow list allows ONLY the options chosen, all other apps/sites are blocked
    - Block list allows all BUT the options chosen
 - Brain Dump
    - Meant for jotting down ideas as you have them and NOT disrupt your focus
